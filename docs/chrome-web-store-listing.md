# เอกสารเตรียมส่ง PhishMail ขึ้น Chrome Web Store

เอกสารนี้รวบรวมข้อความที่ต้องกรอกในแบบฟอร์มของ Chrome Web Store Developer Dashboard
ไว้ให้คัดลอกไปวางได้เลย พร้อมรายการสิ่งที่ยังต้องทำก่อนกดส่ง

> **สถานะ:** ยังส่งไม่ได้ — ดูหัวข้อ "สิ่งที่ต้องแก้ก่อนกดส่ง" ท้ายเอกสาร

## 2. Summary (สูงสุด 132 ตัวอักษร)

```
ตรวจจับและแจ้งเตือนอีเมลฟิชชิงขณะเปิดอ่านใน Gmail โดยใช้เทคนิคการประมวลผลภาษาธรรมชาติ
```

## 3. Detailed description

```
PhishMail ช่วยให้คุณรู้ว่าอีเมลที่กำลังอ่านอยู่มีความเสี่ยงเป็นฟิชชิงหรือไม่
ก่อนที่จะกดลิงก์หรือกรอกข้อมูลใด ๆ

การทำงาน
- เมื่อคุณเปิดอ่านอีเมลใน Gmail ส่วนขยายจะวิเคราะห์หัวข้อและเนื้อหา
- แสดงป้ายระดับความเสี่ยงเป็นเปอร์เซ็นต์ที่มุมขวาล่าง แบ่งเป็น 3 ระดับ
  แดงตั้งแต่ 50% ขึ้นไป เหลืองตั้งแต่ 30% และเขียวเมื่อต่ำกว่านั้น
- กดดูรายละเอียดเพื่อดูว่าพบสัญญาณอะไรบ้าง เช่น การกดดันด้านเวลา
  หรือการขอข้อมูลส่วนตัว พร้อมไฮไลต์คำที่น่าสงสัยในเนื้อหา

ความสามารถ
- รองรับอีเมลทั้งภาษาไทยและภาษาอังกฤษ โดยเลือกแบบจำลองให้อัตโนมัติ
- ภาษาไทยใช้การตัดคำด้วย PyThaiNLP ร่วมกับคลังคำที่ปรับสำหรับบริบทอีเมลฟิชชิง
- ตั้งค่าปลายทาง API ภาษา และเปิด/ปิดการสแกนได้จากหน้าต่างตั้งค่า

ความเป็นส่วนตัว
- ส่วนขยายจะไม่อ่านอีเมลใด ๆ จนกว่าคุณจะกดอนุญาตในหน้าจอข้อตกลง
- อ่านเฉพาะอีเมลฉบับที่เปิดอยู่ ไม่อ่านกล่องจดหมาย ไฟล์แนบ หรือรายชื่อผู้ติดต่อ
- ไม่ส่งข้อมูลให้บุคคลที่สาม ไม่มีโฆษณา ไม่มีการติดตามผู้ใช้
- เนื้อหาอีเมลถูกเข้ารหัสก่อนบันทึกเสมอ และไม่มีการเก็บที่อยู่ผู้ส่งหรือผู้รับ

ส่วนขยายนี้พัฒนาขึ้นเป็นส่วนหนึ่งของปริญญานิพนธ์
เรื่องระบบตรวจจับอีเมลฟิชชิงโดยใช้การประมวลผลภาษาธรรมชาติ
```

## 4. Single purpose description

ช่อง **"Single purpose"** ในแบบฟอร์ม Privacy practices

```
ส่วนขยายนี้มีวัตถุประสงค์เดียวคือ วิเคราะห์เนื้อหาของอีเมลที่ผู้ใช้กำลังเปิดอ่าน
ใน Gmail เพื่อประเมินความเสี่ยงว่าเป็นอีเมลฟิชชิงหรือไม่ แล้วแสดงผลการประเมิน
ให้ผู้ใช้ทราบ ฟังก์ชันทุกอย่างในส่วนขยายสนับสนุนวัตถุประสงค์นี้โดยตรง
```

```
This extension has a single purpose: to analyze the content of the email the
user is currently reading in Gmail, assess whether it is a phishing attempt,
and display the assessment to the user. Every feature in the extension
directly supports this purpose.
```

## 5. คำอธิบายเหตุผลของสิทธิ์ที่ขอ

### `storage`

```
ใช้เก็บการตั้งค่าของผู้ใช้ไว้บนเครื่อง ได้แก่ ที่อยู่ API ที่ผู้ใช้กำหนด
เกณฑ์ระดับความเสี่ยง สถานะเปิด/ปิดการสแกน ภาษาที่เลือก และสถานะความยินยอม
ค่าเหล่านี้จำเป็นต่อการจดจำการตั้งค่าระหว่างการใช้งาน และไม่ถูกส่งออกนอกเครื่อง
```

```
Used to persist the user's own settings on their device: the configured API
endpoint, risk thresholds, scan on/off state, selected language, and consent
status. These are required to remember the user's preferences between sessions
and are never transmitted off the device.
```

### `https://mail.google.com/*`

```
ส่วนขยายต้องอ่านหัวข้อและเนื้อหาของอีเมลที่ผู้ใช้เปิดอ่านอยู่ใน Gmail
เพื่อนำไปวิเคราะห์ความเสี่ยง และต้องแสดงป้ายผลการวิเคราะห์ทับบนหน้า Gmail
จึงจำเป็นต้องขอสิทธิ์เข้าถึงโดเมนนี้ ส่วนขยายจะเริ่มอ่านก็ต่อเมื่อผู้ใช้
กดอนุญาตในหน้าจอข้อตกลงแล้วเท่านั้น และอ่านเฉพาะอีเมลฉบับที่เปิดอยู่
```

```
The extension must read the subject and body of the email the user is currently
viewing in Gmail in order to analyze it, and must render the risk badge on top
of the Gmail page. Reading begins only after the user grants consent on the
consent screen, and only the currently open message is read.
```

### `http://127.0.0.1:8000/*` และ `http://localhost:8000/*`

```
ส่วนขยายส่งเนื้อหาอีเมลไปวิเคราะห์ที่เซิร์ฟเวอร์ซึ่งทำงานอยู่บนเครื่องของผู้ใช้เอง
เพื่อให้ข้อมูลไม่ต้องออกจากเครื่อง จึงต้องขอสิทธิ์เข้าถึง localhost
```

> ดูหมายเหตุในหัวข้อ "สิ่งที่ต้องแก้ก่อนกดส่ง" — การขอสิทธิ์ localhost
> ทำให้ทีมตรวจสอบทดสอบส่วนขยายไม่ได้

## 6. Data usage disclosures

ช่องกาเครื่องหมายในหน้า **Privacy practices**

| รายการ | ตอบ |
|---|---|
| Personally identifiable information | ไม่ |
| Health information | ไม่ |
| Financial and payment information | ไม่ |
| Authentication information | ไม่ |
| Personal communications | **ใช่** — เนื้อหาอีเมลที่ผู้ใช้เปิดอ่าน |
| Location | ไม่ |
| Web history | ไม่ |
| User activity | ไม่ |
| Website content | ไม่ |

ข้อรับรองสามข้อท้ายแบบฟอร์ม ติ๊กได้ทั้งหมด

- ไม่ขายหรือโอนข้อมูลให้บุคคลที่สามนอกเหนือจากกรณีที่ได้รับอนุญาต
- ไม่ใช้หรือโอนข้อมูลเพื่อวัตถุประสงค์อื่นนอกจากฟังก์ชันหลักของส่วนขยาย
- ไม่ใช้หรือโอนข้อมูลเพื่อประเมินความน่าเชื่อถือทางการเงินหรือการให้สินเชื่อ

## 9. สิ่งที่ต้องแก้ก่อนกดส่ง

### ปลายทาง API ชี้ไป localhost

`API_ENDPOINT` ใน `extension/config.js` มีค่าเริ่มต้นเป็น
`http://127.0.0.1:8000/api/v1/analyze`

ทีมตรวจสอบของ Google จะติดตั้งส่วนขยายบนเครื่องของตนซึ่ง **ไม่มีเซิร์ฟเวอร์นี้ทำงานอยู่**
ส่วนขยายจะแสดงข้อความว่าวิเคราะห์ไม่สำเร็จ และมีโอกาสสูงที่จะถูกปฏิเสธ
ด้วยเหตุผลว่าใช้งานไม่ได้

**ต้องทำก่อน:** นำ backend ขึ้นเซิร์ฟเวอร์สาธารณะที่ใช้ HTTPS แล้วแก้
`API_ENDPOINT` และ `host_permissions` ใน `manifest.json` ให้ชี้ไปที่โดเมนนั้น

### ยังไม่มีภาพหน้าจอ

ต้องมีอย่างน้อย 1 ภาพขนาด 1280×800 แนะนำให้ถ่าย

1. ป้ายระดับความเสี่ยงที่แสดงบนอีเมลฟิชชิงใน Gmail
2. หน้าต่างรายงานผลการวิเคราะห์
3. หน้าจอข้อตกลงความเป็นส่วนตัว

### ค่าธรรมเนียมนักพัฒนา

ต้องชำระ 5 ดอลลาร์สหรัฐครั้งเดียวต่อบัญชี ก่อนเผยแพร่ส่วนขยายแรก

## สรุปขั้นตอน

1. นำ backend ขึ้น HTTPS แล้วแก้ `API_ENDPOINT` กับ `host_permissions`
2. ถ่ายภาพหน้าจอ 1280×800
3. เปิด URL นโยบายความเป็นส่วนตัวให้เข้าถึงได้สาธารณะ
4. สร้างไฟล์ ZIP จากโฟลเดอร์ `extension/`
5. ชำระค่าธรรมเนียม 5 ดอลลาร์ที่ Developer Dashboard
6. อัปโหลด กรอกข้อมูลจากเอกสารนี้ ตั้ง Visibility เป็น Unlisted แล้วกดส่ง

ระยะเวลาตรวจสอบโดยทั่วไป 1 ถึง 7 วันทำการ ส่วนขยายที่อ่านเนื้อหาอีเมล
มักถูกตรวจสอบเข้มกว่าปกติและอาจถูกขอข้อมูลเพิ่มเติม
